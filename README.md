# TEDÜ Gelecek Projeksiyonu

Küresel ve yerel öngörüler, kurumsal dönüşüm ve strateji.

Statik rapor sayfası. `index.html` ana raporu, `kaynaklar.html` kaynak dizinini ve `downloads/` rapor eklerini içerir. GitHub Pages kaynağı: ana dalın kök dizini. `.nojekyll` dosyası sayfanın olduğu gibi yayımlanmasını sağlar.

Arama motorlarının dizine eklememesi istenir; bu ayar erişim kısıtlaması sağlamaz.
